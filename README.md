# Hermes
making a chatroom messenger thing  
node.js required (cmd: node server.js)  
sqlite db soon™  

# Warnings
MAKE SURE NODE IS NOT ON SAME PORT AS LIVE PREVIEW (3000)  
CHANGE PORT AT BOTTOM OF server.js  

# Progress and Goals
Unfriend - Only friend  
Unlimited rooms - Currently only 1  
Send all formats - Currently only text  
User customization - In Progress  
Client Customization - 3 Themes  
User to User Direct Messaging - None  
Calling and Voice channels - None  
SQLite DB - Currently Json db  

# Commands
/help - show all commands  
/friend <username> - add a friend  
/unfriend <username> - remove a friend (Doesnt work yet)  
/customize - send to customization page, only themes currently work  
/logout - logout of account
